# ScanPro AI V2.7 — import droit corrigé, bouton Scan central, partages

## Sortie d'import corrigée
- Problème signalé : un document importé déjà droit ressortait pivoté et rogné dans le PDF téléchargé.
- Cause : la détection automatique acceptait un quadrilatère intérieur (tableau/bordures du document) et le redressement pouvait pivoter une page déjà droite, notamment avec un filigrane diagonal.
- Corrections :
  - critères d'acceptation beaucoup plus stricts pour les **images importées** (surface et coins proches des bords) ;
  - redressement appliqué seulement si l'angle est d'au moins 1° **et** le gain d'alignement mesuré dépasse 15 % ;
  - la détection caméra reste active (non-régression V2 : 16/16).
- Test : image A4 déjà droite avec tableau interne et filigrane « SPECIMEN » → aucun quadrilatère appliqué, deskew = 0.

## Bouton Scan
- Placé exactement au centre de la barre basse (Accueil · Documents · **Scan** · Outils · Paramètres).
- Fond bleu nuit neutre (#0B1B34) au lieu du bleu vif, icône blanche.

## Partage multi-format
- Le bouton Partager ouvre le choix : **PDF, Word (.docx), Excel (.xlsx), Texte (.txt)**.
- Excel : champs facture structurés si le texte s'y prête, sinon lignes du texte OCR ; classeur OOXML vérifié.
- Sans texte OCR, message explicite demandant de lancer l'OCR ; repli téléchargement si le partage natif est indisponible.
