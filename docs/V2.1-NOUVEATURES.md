# ScanPro AI — V2.1 : finitions mobiles

> Version publiée : **2.1.0** · https://azharshahim.github.io/Scanpro-ai/

## Nouveautés

| Fonctionnalité | Comportement | Vérification |
|---|---|---|
| **Réorganisation des pages par glisser** | appui long (260 ms) sur une vignette → vibration → déplacement horizontal ; insertion calculée sur les centres des vignettes ; défilement automatique près des bords | ordre `pgm1,pgm2,pgm3` → `pgm2,pgm3,pgm1`, index réenregistrés 0,1,2 |
| **OCR d'une zone** | sélecteur rectangulaire au doigt sur la page ; la zone est recadrée, agrandie (×1 à ×3) puis analysée par Tesseract ; résultat éditable, copiable ou **ajouté au texte du document** | « PAGE 2 » reconnu sur une zone de 35 % de la hauteur |
| **Mode rafale** | capture automatique toutes les 1,2 s (max 20 pages), bouton d'arrêt, compteur en direct, arrêt automatique en quittant la caméra | 4 pages capturées puis arrêt confirmé |
| **Balayage entre les pages** | glissement horizontal dans l'aperçu → page précédente / suivante | page 1 → page 2 |
| Accès | outil « Zone OCR » dans l'éditeur + bouton « OCR d'une zone » dans la fiche document | — |

## Détails techniques

- **Glisser-déposer** : `pointerdown` + appui long, puis suivi `touchmove` avec `preventDefault`
  (nécessaire car Chrome Android émet un `pointercancel` dès qu'il veut faire défiler) et
  `touch-action` forcé sur la bande en mode réorganisation. Le réordonnancement est appliqué au
  relâchement, puis les pages sont réécrites avec leurs nouveaux `index` dans IndexedDB.
- **OCR de zone** : rendu de la page à 2000 px (pipeline V2 appliqué : perspective + filtre),
  recadrage exact, agrandissement bilinéaire jusqu'à 1600 px de côté, puis OCR.
- **Rafale** : `setInterval` de 1200 ms avec verrou anti-chevauchement ; la détection de contours
  reste active sur chaque prise ; le mode reprend le filtre par défaut à l'arrêt.

## Limites connues de la V2.1

1. **Rafale** : cadence fixe (pas de détection de stabilité réelle) ; sur un téléphone lent,
   la détection de contours peut allonger l'intervalle effectif.
2. **Réorganisation** : uniquement horizontale, dans la bande de vignettes ; pas de déplacement
   entre documents.
3. **OCR de zone** : une seule zone à la fois (pas de multi-sélection), et la zone est agrandie
   sans amélioration de netteté si la photo est floue.
4. **Balayage** : uniquement en mode « Aperçu » (pas dans le texte OCR).
5. Le lasso incliné n'est pas géré : seule une zone rectangulaire est possible.
