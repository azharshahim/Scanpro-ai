# ScanPro AI V2.6 — mode nuit corrigé et menu Outils

## Mode nuit réellement complet
- Cause du bug : les variables sombres du thème n'étaient pas redéfinies à la racine ; le fond et les cartes du milieu restaient donc clairs malgré l'activation.
- Correction : variables `--bg`, `--card`, `--line`, `--muted` redéfinies pour `html[data-theme="dark"]`, fond forcé sur `body`, `#app`, `.view` et `.content`, surfaces (cartes, groupes de réglages, feuilles, champs, onglets, navigation) assombries.
- Vérification par couleurs calculées : fond et milieu de page `rgb(7, 13, 24)` en mode nuit, retour clair confirmé.

## Menu Outils
- Nouvel onglet **Outils** dans la navigation basse, grille d'icônes inspirée des scanners mobiles : Scanner, Convertir, Modifier, Utilitaires.
- Chaque tuile déclenche une action réelle : caméra, rafale, imports, fusion, modes, conversion PDF/images/DOCX/TXT, extraction de pages, nettoyage magique, gomme, signature/filigrane, réorganisation, OCR et OCR de zone, impression, sauvegarde/restauration, doublons, langues OCR, nuit/jour, paramètres, assistant local.
- Les outils nécessitant un document ouvrent d'abord un sélecteur de document ; les originaux sont conservés.
- Aucun bouton décoratif : l'assistant IA génératif distant reste indiqué comme « prévu plus tard » car aucune clé API/backend n'est disponible.
