# ScanPro AI V2.2 — Nettoyage magique, OCR et PDF avancés

Branche : `feature/v2.2` (à partir de la V2.1 stable). Aucune fonctionnalité V1/V2/V2.1 n'est supprimée.

## Implémenté et testé

### Nettoyage magique (P0)
- Correction d'éclairage irrégulier et des ombres (`Vision.magicClean`, fond estimé puis normalisation).
- Nettoyage des fonds gris/jaunis : percentiles robustes, fond poussé vers le blanc sans inventer de texte.
- Débruitage : médiane 3×3 uniquement sur pixels quasi isolés (poussières/taches), puis accentuation.
- Le nettoyage est appliqué dans `ImageOps.render`, donc **dans l'image exportée en PDF**, pas seulement à l'aperçu.
- Original préservé : `page.src` n'est jamais réécrit ; seuls `cleanup`, `adj`, `filter`, `eraser` sont persistés.
- Studio : avant/après avec curseur, zoom, Amélioration automatique, Nettoyage magique, Noir et blanc,
  Restaurer l'original, Annuler/Rétablir (historique des réglages), gomme tactile non destructive,
  application à toutes les pages, enregistrement d'une copie nettoyée.
- Mesure de test (facture synthétique ombrée) : luminance moyenne du fond **192,6 → 217,6**, texte sombre conservé, OCR lisant « FACTURE FAC-2026-042 ».

### OCR V2.2
- FR+EN existant conservé, ordre du texte conservé par Tesseract.
- Mots incertains (< 60 %) collectés et affichés dans l'onglet Texte.
- Export **TXT** et **DOCX** (OOXML généré localement via JSZip) du texte modifiable.

### PDF avancé
- Existant conservé : génération, fusion, téléchargement, partage, impression, export images.
- Nouveau : extraction/division de pages d'un PDF importé (`1-2, 4`), nouveau document créé, original conservé.
- Nouveau : PDF enrichi avec numéros de page, filigrane personnalisé et signature manuscrite dessinée au doigt.
- PDF chiffré/protégé : message explicite, aucun fichier incorrect produit.

### Factures (local, à vérifier)
- Extraction par règles : fournisseur/entreprise, numéro, dates d'émission/échéance, HT, taux et montant TVA,
  TTC, devise, SIREN/SIRET, référence commande.
- Tableau modifiable avant export **CSV/JSON**. Valeur absente = « Non détecté » (jamais inventée).
- Ce n'est **pas** une validation comptable officielle.

### Bibliothèque
- Favoris, catégorie et étiquettes (persistés), filtre « Favoris », affichage dans les cartes, historique de création/favoris.

### Assistant distant
- Non configuré volontairement : aucun envoi, aucune clé API dans le navigateur. Les fonctions locales restent actives.

## Limites connues
- Pas de reconstruction générative : un texte masqué/illisible n'est pas « restauré » ; la gomme masque en blanc.
- Le débruitage est volontairement léger pour ne pas effacer de caractères fins.
- L'extraction facture par règles dépend fortement de la qualité OCR et de la mise en page.
- DOCX simple (paragraphes), pas de mise en page complexe ni tableaux.
- Extraction PDF : les PDF réellement chiffrés nécessitant un mot de passe sont refusés explicitement.
- Assistant IA génératif, mode livre/courbure, APK natif : non implémentés dans cette branche.
- Publication GitHub : nécessite un jeton valide ; aucun secret n'est stocké dans le dépôt.
